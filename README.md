# Speak German with Confidence

The complete A1–C1 course-outline website for `learngerman.detleng.com`.

## Preview locally

Open `index.html` directly, or serve the folder with any static server.

## Publish

The site is dependency-free and ready for GitHub Pages. Keep the included `CNAME` file at the repository root.

## Editing course content

All curriculum content lives in `course-data.js`. Add lesson content later inside the relevant chapter object without changing the page design.
